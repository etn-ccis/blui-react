# Slashed Icon

`SlashedSvgIcon` adds a slash to an SVG icon at runtime. Use `size` to set its dimensions and `slashColor` to change the slash color.

### Slashed Icon API

<Box>

| Prop Name  | Description                                     | Type     | Required | Default          |
| :--------- | :---------------------------------------------- | :------- | :------- | :--------------- |
| iconSrc    | URL of a bundled, trusted, same-origin SVG      | `string` | yes      |                  |
| size       | Width and height of the rendered icon in pixels | `number` | no       | `48`             |
| slashColor | Color of the slash                              | `string` | no       | `'currentColor'` |
| alt        | Accessible label for the icon                   | `string` | no       | `''`             |

</Box>
