## Slashed Icon

`SlashedSvgIcon` adds a slash to an SVG icon at runtime, often to show that a device is off, unavailable, or in a negative state.

Pass a bundled SVG asset URL to `iconSrc`. You can optionally change the slash color and size.

<SlashedIconExample />

<CodeBlock
    language={'jsx'}
    code={`import { SlashedSvgIcon } from '@brightlayer-ui/icons-mui';
import BatteryIcon from '@brightlayer-ui/icons-svg/battery.svg';
    import AccountSettingsIcon from '@brightlayer-ui/icons-svg/account_settings.svg';
    import BuildingIcon from '@brightlayer-ui/icons-svg/building.svg';
    import DeviceIcon from '@brightlayer-ui/icons-svg/device.svg';

    <SlashedSvgIcon iconSrc={BatteryIcon} size={48} alt="Battery disabled" />

    <SlashedSvgIcon iconSrc={AccountSettingsIcon} size={48} slashColor="#CA3C3D" alt="Account settings unavailable" />

    <SlashedSvgIcon iconSrc={BuildingIcon} size={48} slashColor="#1C77CC" alt="Building unavailable" />

    <SlashedSvgIcon iconSrc={DeviceIcon} size={48} alt="Device disabled" />`}
/>
